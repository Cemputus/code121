# Daystar Daycare Center Management System

A comprehensive management system for Daystar Daycare Center, built with React, TypeScript, and Tailwind CSS.

## Features

- Babysitter Management
  - Registration and profile management
  - Payment tracking
  - Scheduling and attendance
- Child Management
  - Registration and profile management
  - Attendance tracking
  - Special care needs tracking
- Financial Management
  - Income and expense tracking
  - Budget management
  - Financial reporting
- User Authentication
  - Secure login system
  - Role-based access control

## Prerequisites

- Node.js (v14 or higher)
- npm (v6 or higher)

## Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd daystar-daycare-frontend
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm start
```

The application will be available at `http://localhost:3000`.

## Project Structure

```
src/
  ├── components/     # Reusable UI components
  ├── pages/         # Page components
  ├── App.tsx        # Main application component
  ├── index.tsx      # Application entry point
  └── index.css      # Global styles
```
